# Dataset

## HDTF_TFHP Dataset

This project uses the HDTF_TFHP dataset from the DiffPoseTalk project.

### Download

Please refer to the official dataset instructions:
- [HDTF_TFHP Dataset README](https://github.com/DiffPoseTalk/DiffPoseTalk/blob/main/datasets/HDTF_TFHP/README.md)

### Dataset Structure

After downloading, place the data in this folder following the structure specified in the official repository.

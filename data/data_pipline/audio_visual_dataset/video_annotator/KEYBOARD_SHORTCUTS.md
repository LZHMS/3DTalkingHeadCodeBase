# 键盘快捷键完整列表

## 通用快捷键（所有模式）

| 按键 | 功能 | 说明 |
|------|------|------|
| `空格` | 播放/暂停 | 切换视频播放状态 |
| `1` | 0.5x速度 | 慢速播放 |
| `2` | 1x速度 | 正常速度 |
| `3` | 1.5x速度 | 快速播放 |
| `←` | 后退5秒 | 向前跳转5秒 |
| `→` | 前进5秒 | 向后跳转5秒 |
| `H` | 显示/隐藏帮助 | 切换快捷键帮助面板 |

## URL模式快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| `I` | 设置起点 | 标记片段起始时间 |
| `O` | 设置终点 | 标记片段结束时间 |
| `Enter` | 添加片段 | 将标记的片段添加到列表 |

## 本地片段模式快捷键

### 片段导航

| 按键 | 功能 | 说明 |
|------|------|------|
| `F` | 下一个片段 | 播放下一个片段（无需确认） |
| `A` | 上一个片段 | 播放上一个片段 |

### 片段管理

| 按键 | 功能 | 说明 |
|------|------|------|
| `D` | 删除片段 | **快速删除当前片段（无确认对话框）** |

⚠️ **重要**: 删除操作不可恢复！请谨慎使用。

### 片段截取

| 按键 | 功能 | 说明 |
|------|------|------|
| `S` | 设置截取起点 | 在当前播放位置标记新片段起点 |
| `E` | 设置截取终点 | 在当前播放位置标记新片段终点 |
| `X` | 执行截取 | **快速截取并替换（无确认对话框）** |
| `C` | 取消截取 | 取消截取操作，清除标记 |

⚠️ **重要**: 截取会删除原片段！请谨慎使用。

## 快捷键工作流程示例

### 快速浏览和筛选片段

```
1. 选择一个视频
2. 按 F 查看下一个片段
3. 如果不需要，按 D 删除
4. 继续按 F 查看下一个
5. 重复步骤3-4直到完成
```

**效率**: 每个片段只需2次按键（F查看 + D删除或F跳过）

### 精细截取片段

```
1. 播放到需要截取的片段
2. 按空格暂停
3. 移动到起点位置，按 S 设置起点
4. 移动到终点位置，按 E 设置终点
5. 按 X 执行截取
6. 按 F 继续下一个片段
```

**效率**: 完全键盘操作，无需鼠标

### 仅使用键盘完成所有操作

```
启动后:
H          - 查看快捷键帮助
空格        - 播放/暂停
1/2/3      - 调整速度
←/→        - 精确定位
S          - 标记截取起点
E          - 标记截取终点  
X          - 执行截取
D          - 删除不需要的
F          - 下一个片段
A          - 上一个片段
```

## 高级技巧

### 1. 快速筛选模式
```
目标: 快速浏览所有片段，删除不需要的

操作: F D F D F D F ...
说明: F查看下一个，D删除当前（如需要）
```

### 2. 精确截取模式
```
目标: 从长片段中提取精确的小片段

操作:
- 空格暂停
- ← 或 → 微调位置
- S 标记起点
- → → → 前进到终点
- E 标记终点
- X 执行截取
```

### 3. 批量处理模式
```
目标: 处理大量片段

建议工作流:
1. 第一遍: 快速删除明显不需要的（F + D）
2. 第二遍: 对剩余片段进行精确截取（S + E + X）
3. 第三遍: 最终检查（F浏览，必要时D删除）
```

## 注意事项

### 快速操作模式的好处
- ✅ 提高效率：无需鼠标点击
- ✅ 减少确认：信任用户操作
- ✅ 流畅工作流：连续按键即可完成

### 需要注意的地方
- ⚠️ **D键删除无确认**: 操作不可恢复，删除后立即生效
- ⚠️ **X键截取无确认**: 会删除原片段并替换为新片段
- ⚠️ **建议备份**: 处理重要数据前建议先备份
- ⚠️ **查看控制台**: 所有操作都有日志输出（F12打开控制台）

### 如果误操作
- 删除操作无法撤销
- 但后端服务器有详细日志
- 可以从 `corrupted_backup` 查看是否有备份
- 建议定期备份整个 `output_clips` 目录

## 键盘布局建议

为了更高效，建议将双手放置在：
- **左手**: A S D F 键区域（片段导航、截取起点、删除、下一个）
- **右手**: 方向键 + 数字键（播放控制、速度调整）

这样可以实现盲打操作，提升处理速度。

## 自定义提示

如果需要修改快捷键，编辑 `app.js` 中的 `handleKeyboard` 函数：

```javascript
case 'd':  // 改为其他键
    if (appMode === 'local' && currentClips.length > 0) {
        e.preventDefault();
        deleteCurrentClipQuick();
    }
    break;
```

## 快捷键冲突说明

- 快捷键仅在**非输入框**时生效
- 如果焦点在输入框（INPUT或TEXTAREA），快捷键被禁用
- 这样可以在需要输入文本时不触发快捷键

## 调试模式

所有快捷键操作都会在浏览器控制台输出日志：
```
按F12打开控制台
查看类似这样的输出:
- "快速删除片段: scene_2"
- "快速截取: 00:00:05 - 00:00:15"
```

这有助于确认操作是否正确执行。

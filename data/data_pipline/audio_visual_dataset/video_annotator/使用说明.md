# 视频片段标注与管理工具 - 使用说明

## 概述

本工具已升级为支持双模式的视频管理系统：
1. **URL模式**：原有的YouTube视频在线标注功能
2. **本地片段模式**：新增的本地视频片段浏览、删除和截取功能

## 安装和启动

### 第一步：安装Python依赖

```bash
cd video_annotator
pip install -r requirements.txt
```

这会安装：
- Flask（Web框架）
- Flask-CORS（跨域支持）

### 第二步：安装FFmpeg

视频截取功能需要FFmpeg。

**Windows用户：**
1. 访问 https://ffmpeg.org/download.html
2. 下载Windows版本
3. 解压到一个目录（例如 `C:\ffmpeg`）
4. 将 `C:\ffmpeg\bin` 添加到系统环境变量PATH

**验证安装：**
```bash
ffmpeg -version
```

### 第三步：启动服务器

**方法1：使用批处理文件（推荐）**
```
双击 start_server.bat
```

**方法2：命令行启动**
```bash
python server.py
```

服务器会在 http://localhost:5000 启动

### 第四步：打开前端页面

在浏览器中打开 `index.html` 文件

## 本地片段模式详细使用

### 1. 切换到本地片段模式

点击左上角的"本地片段"按钮

### 2. 选择分类和视频

1. 从"分类"下拉菜单选择分类（如Lecture、Speech）
2. 点击视频列表中的任意视频
3. 系统会自动加载该视频的所有场景片段

### 3. 浏览和播放片段

- 视频会自动播放第一个片段
- 顶部显示当前片段信息（ID和时长）
- 使用"◄ 上一个"和"下一个 ►"按钮在片段间切换
- 片段位置显示（如 "3 / 10" 表示共10个片段，当前是第3个）

### 4. 播放控制

- **播放/暂停**：点击按钮或按空格键
- **调速**：点击 0.5x、1x、1.5x 按钮
- **进度条**：点击时间轴跳转到指定位置

### 5. 删除片段

**操作步骤：**
1. 播放到要删除的片段
2. 点击"🗑️ 删除当前片段"按钮
3. 在确认对话框中点击"确定"

**自动操作：**
- ✓ 删除 `.mp4` 视频文件
- ✓ 删除 `.m4a` 音频文件
- ✓ 从 `scene_info.json` 移除该片段记录
- ✓ 更新 `video_scece_info.txt` 并重新编号
- ✓ 自动跳转到下一个或上一个片段

**注意：** 此操作不可恢复！

### 6. 截取新片段

**使用场景：** 当前片段太长，只想保留其中一部分

**操作步骤：**
1. 播放到要截取的片段
2. 点击"✂️ 截取新片段"按钮
3. 展开的面板中：
   - 移动视频到新片段的起始位置
   - 点击"新起始时间"旁的"设置"按钮
   - 移动视频到新片段的结束位置
   - 点击"新结束时间"旁的"设置"按钮
4. 点击"确认截取并删除原片段"按钮
5. 在确认对话框中点击"确定"

**自动操作：**
- ✓ 使用FFmpeg从原片段截取新片段
- ✓ 保持视频和音频同步
- ✓ 删除原片段文件
- ✓ 用新片段替换
- ✓ 更新 `scene_info.json` 中的时间、帧数等信息
- ✓ 更新 `video_scece_info.txt` 的时间记录
- ✓ 自动重新加载新片段

**注意：** 此操作不可恢复！

### 7. 时间轴可视化

- 绿色竖线：起始标记
- 红色竖线：结束标记
- 橙色竖线：当前播放位置
- 点击时间轴可快速跳转

## URL模式使用（原有功能）

1. 点击"URL模式"按钮
2. 点击"📁 上传 .txt 文件"上传YouTube链接列表
3. 选择视频进行播放
4. 使用快捷键标注片段：
   - `I` - 设置起始时间
   - `O` - 设置结束时间
   - `Enter` - 添加片段
   - `空格` - 播放/暂停
5. 点击"导出 JSON"保存标注结果

## 文件结构说明

```
output_clips/
├── Lecture/                          # 分类文件夹
│   ├── _jcW-ZgpRbM/                 # 视频ID文件夹
│   │   ├── scene_1.mp4              # 场景1视频
│   │   ├── scene_1.m4a              # 场景1音频
│   │   ├── scene_2.mp4              # 场景2视频
│   │   ├── scene_2.m4a              # 场景2音频
│   │   ├── scene_info.json          # 场景元数据（JSONL格式）
│   │   └── video_scece_info.txt     # 场景时间信息（文本格式）
│   └── ...
└── Speech/                           # 另一个分类
    └── ...
```

### scene_info.json 格式

每行一个JSON对象（JSONL格式）：
```json
{"id":"scene_1","video-path":"...","start-time":0.903,"end-time":5.903,"durations":"5.0s",...}
{"id":"scene_2","video-path":"...","start-time":183.128,"end-time":208.128,"durations":"25.0s",...}
```

### video_scece_info.txt 格式

```
scene 1 infos: start_time 0:0, end_time 0:5
scene 2 infos: start_time 3:3, end_time 3:28
```

## 常见问题

### Q: 提示"无法连接到服务器"
**A:** 检查后端服务器是否已启动。应该在终端看到：
```
* Running on http://127.0.0.1:5000
```

### Q: 删除功能无响应
**A:** 检查：
1. 浏览器控制台（F12）是否有错误
2. 后端服务器终端是否有错误输出
3. 文件权限是否正确

### Q: 截取功能报错
**A:** 确保：
1. FFmpeg已正确安装并在PATH中
2. 视频文件存在且可访问
3. 有足够的磁盘空间

### Q: 更新的信息文件格式不对
**A:** 
- scene_info.json 使用JSONL格式（每行一个JSON）
- 确保原始文件格式正确
- 查看后端日志了解具体错误

### Q: 视频无法播放
**A:** 
- 检查视频文件路径是否正确
- 确认浏览器支持该视频格式
- 查看浏览器控制台的网络请求

## 高级技巧

### 批量处理建议
1. 先浏览所有片段，记录要删除的编号
2. 从后往前删除（避免编号变化）
3. 截取操作建议一次只处理一个

### 备份建议
重要操作前建议备份：
```bash
# 备份整个视频文件夹
cp -r output_clips/Lecture/_jcW-ZgpRbM output_clips/Lecture/_jcW-ZgpRbM_backup

# 或至少备份信息文件
cp scene_info.json scene_info.json.bak
cp video_scece_info.txt video_scece_info.txt.bak
```

### 性能优化
- 大量片段时，考虑分批处理
- 关闭其他占用资源的应用
- 使用SSD存储视频文件

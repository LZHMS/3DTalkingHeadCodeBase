## FLAME Official Model

From the [official FLAME project website](https://flame.is.tue.mpg.de/), download the following files:

1. Download the **FLAME 2020 model** and unzip it to the `FLAME2020` folder
2. Download `landmark_embedding.npy` to this folder
3. Download `FLAME_masks.pkl` to this folder
